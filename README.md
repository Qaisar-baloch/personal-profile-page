# Personal Profile Page

A small static personal-profile website created as an introductory web development exercise. It uses plain HTML and CSS without a frontend framework or build tool.

This is an earlier learning project and is separate from my current portfolio:
https://qaisar-portfolio-rose.vercel.app/

## Implementation

- Semantic HTML page structure.
- A profile card with About Me, Skills and Contact sections.
- A linked CSS stylesheet.
- Responsive adjustments for narrower screens.
- Basic hover styling for links.

## Run locally

Clone the repository and open index.html in a web browser. No package installation or build command is required.

~~~bash
git clone https://github.com/Qaisar-baloch/personal-profile-page.git
cd personal-profile-page
~~~
